# research/: the evidence behind this repository

> **Amnesiac landing.** Zero prior context assumed. Process: `../docs/2-how-to/HOW-TO-INGEST-RESEARCH.md`.
> Machine index: `INDEX.json` (generated). Human index: `INDEX.md` (generated).

## What is this?

Every research document this project relies on, filed so that any agent or person can find what it says, how strong it is, and where exactly it says it, without rereading it. Public: the corpus holds the owner's own documents verbatim and third-party work as citation plus summary, never full copyrighted text, never anything private.

## What lives here

| Path | What |
|---|---|
| `corpus/<id>.md` | One card per document: front matter (id, kind, subjects, evidence, origin, captured, status, summary) + the text. Figures under `corpus/assets/<id>/`. |
| `FINDINGS.jsonl` | One atomic finding per line: situation → finding → best move → why → avoid → source (`source_key` or `corpus_refs` with line ranges) → strength → caveat → status (`checked` only with a verified source). |
| `SOURCES.json` | Checked primary sources, each loaded by `scripts/research/verify.mjs` with what was found and when. |
| `SUBJECTS.json` | The taxonomy: subjects, kinds, evidence levels, strengths. |
| `INDEX.json`, `INDEX.md` | Generated by `node scripts/research/index.mjs`. Never hand-edit. |
| `_inbox/` | Candidates a model or a subagent produced, awaiting a person's validation. Nothing here is a finding yet. |
| `retrieval/`, `.vectors/` | Derived, gitignored: retrieval packs (`research:pack`) and embedding caches (`research:ask -- --build`). |
| `research.config.json` | Endpoints, models, chunking and thresholds. Environment variables override every value. |

## Use

```bash
node scripts/research/ask.mjs "<situation or question>"      # ask first: ranked findings and passages
node scripts/research/card.mjs <doc.md> --id <id> --kind owner-research --subjects a,b --summary "..."   # file a document
node scripts/research/index.mjs                                 # rebuild the index (npm run verify checks it is fresh)
node scripts/research/pack.mjs <id>                             # deterministic retrieval pack
node scripts/research/overlap.mjs <id>                          # what a new card adds vs existing findings
node scripts/research/extract.mjs <id>                          # local-model finding candidates into _inbox/
node scripts/research/verify.mjs --key <k> --arxiv <id>         # load a primary source, record it in SOURCES.json
```

Every tool talks to whatever model endpoint `research.config.json` or the environment names; the defaults are local.

## Never

Secrets or personal data in a card · full text of third-party works · hand-edited INDEX files · a `checked` status without a `SOURCES.json` entry · vectors from two models in one cache.
