## Details

scripts/story-variants.mjs: list, render, diff, apply over <story-folder>/variants.json (scripts/variants.v1.schema.json). A variant is named steps applied to the rendered text of an edition, never to the records: replace a phrase in one spread, in every spread, or in the one spread that holds it (none or several fail); drop spreads; a banner line; add a spread from a draft; names compose with +; every phrase is a token source resolved before matching, so a tested text is reproducible from its name. apply: checks that every record reads back from its own built text, renders the tested text (equal to the --tested file or it stops), parses each spread back into its fields, writes only the fields that differ with names put back as tokens and verified by resolving them again (a speaker is one token; a shared label stops the run), retires dropped spreads in every edition and parks their pictures, writes a tested banner to the edition's new banner field, turns an added spread into a new-* slot holding _slot (variant, time, neighbour, position in every edition) and _draft (the draft as tested, as tokens) and no field, rebuilds built/, re-renders the written records and requires them equal to the tested text spread for spread (a slot by position only), runs the names gate, and on any failure puts every file back; one entry per run in variants-applied.json. The loader (story.mjs) treats a new-* slug as a slot: notes only, placed or retired like any scene, rendered as a SLOT block; a slot with paragraphs or dialogue, or any other field, fails every story command with the fix (rename it to claim it). Example: six variants on the public cast in examples/story/variants.json; the composed variant round-trips on a copy with zero differences and every gate green. Docs: the how-to (measure before you make it; the machine writes the winner back; what an AI may never write), the reference (steps, refusals, apply in order, the slot, the banner, the applied record), ADR-007; README section, PRODUCT row, routing line. The how-to's commands were replayed in a fresh git copy, output equal to the doc. Nothing of the private story (prose, names, art, paths) crossed.
