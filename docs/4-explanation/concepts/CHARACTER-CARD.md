# Character card

*Also called:* character model sheet, turnaround, character bible, golden record, master data

**What it is:** One page per character that says exactly how they look: face, body, hair, clothes, and the marks that never change. It shows them from the front, the side and the back.

**Why it matters:** When many pictures are made by many people or tools, each one guesses a little. The card stops the guessing. Every picture is drawn from the card, so the character stays the same person.

**The rule here:** A character's look lives only on their card. A scene, a prompt or a file never retypes it. A picture is checked against the card, never against an older picture.

**How to use it:** Before the first scene, fill in the card's fields in `character-registry.json`, including the four views. Point every prompt at the card by token.

**Next step:** Read [Registry fields](../../3-reference/REGISTRY-FIELDS.md), then add the four views for one character.

## How it connects

The card is the [one home](ONE-HOME-FOR-EACH-FACT.md) for a character's look. A [quality gate](GATE.md) compares each new picture with it. When a picture is wrong, you make a [fresh render](FRESH-RENDER-NOT-A-PATCH.md) from the card instead of fixing the old picture.

**Source:** *Producing Animation* (Winder and Dowlatabadi, 2019): finding `eadp-11` in [research findings](../../../research/FINDINGS.jsonl), status checked.
