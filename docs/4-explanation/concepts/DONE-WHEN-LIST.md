# Done-when list

*Also called:* acceptance criteria, definition of done, exit criteria

**What it is:** A short list, written before the work starts, of what must be true for the work to count as done.

**Why it matters:** Without it, done means whatever the maker felt. With it, anyone can check.

**The rule here:** Every task has a done-when list. Each line can be checked by a person or a script.

**How to use it:** Write each line as a fact you can test, like "the page links every concept page", not a wish.

**Next step:** Add a done-when list to the [brief](BRIEF.md) for your next task.

## How it connects

A [quality gate](GATE.md) is a done-when list that a computer checks. For a picture, the character's card is the done-when list, and the [on-model check](ON-MODEL-CHECK.md) turns each card line into a yes or no test.
