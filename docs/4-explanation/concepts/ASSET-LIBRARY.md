# Asset library

*Also called:* digital asset management, DAM, media library, asset register

**What it is:** The one place where finished pictures and other files are kept, each with a name, a version and a status.

**Why it matters:** When files sit in many folders with loose names, people reuse the wrong one or lose the right one.

**The rule here:** Each picture has one home in the library and one place where it is used. A new version gets a new file name by slot and version, never by a person's name.

**How to use it:** Name each file by where it goes and its version. Store a [made-by record](MADE-BY-RECORD.md) next to it.

**Next step:** List the pictures in one story and check that each has one home and one use.

## How it connects

The library holds the files. The [approval steps](APPROVAL-STEPS.md) say which files are ready to use.
