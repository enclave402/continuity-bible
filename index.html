Narrative Token SSOT

Character names as build-time tokens, so AI agents can't drift them. One registry file is the single source of truth for every name in your scenes, prompts and image manifests. Plain Node, zero dependencies, no telemetry, MIT.

Quick start GitHub See it live Antidote Kit

The problem

When you write multi-scene stories, graphic novels or game dialogue with LLMs, names drift. Samantha becomes Sam, Chloe becomes Clara. Renaming a character means a risky find-and-replace across hundreds of files. A rule in the agent's instructions makes drift rarer. It doesn't make it impossible.

The fix

Never write a raw name. Write a token, and resolve it at build time from character-registry.json.

You write

{{chloe-jenkins}} turned around. "Did {{theo-vance:first}} answer you?"
{{sam-hayes:first}} shook her head. "{{theo-vance:formal}} has gone completely silent."

The build prints

Chloe turned around. "Did Theo answer you?"
Sam shook her head. "Theodore has gone completely silent."

To rename a character, change one line in the registry and rebuild. An unknown id fails the build instead of printing a guessed name.

Quick start

git clone https://github.com/enclave402/narrative-token-ssot.git
cd narrative-token-ssot
node scripts/build.mjs

No install, no account, no API key. It prints the example scene as written (tokens), then resolved (names).

Tokens

TokenResolves to
{{id}}Display name (Sam)
{{id:first}}First word of the display name (Rowan Thorne → Rowan)
{{id:full}}Full name from the registry (Samantha Hayes)
{{id:formal}}Any form declared under forms (Samantha)
{{id:initial}}First initial (S)

Migrate and gate

node scripts/tokenize.mjs drafts/scene-14.md --text --dry-run   # show what would change
node scripts/tokenize.mjs drafts/scene-14.md --text             # rewrite names into tokens
npm run check   # exit 1 if any name is typed out or doesn't resolve
npm test

Put check in a pre-commit hook or CI. Agents in Claude Code, Cursor or Codex can read AGENTS.md for the rule and the checks.

Where it's used

It came out of, and still runs, the build for Dating Red Flags, an illustrated graphic novel on rel8r.me: 82 illustrated scenes across two editions, with every character name resolved from one registry file.
